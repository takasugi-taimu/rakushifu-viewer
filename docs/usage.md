# 利用ガイド

従業員本人のアカウントでログインし、所属店舗のシフトとメンバーを閲覧します。カレンダー・検索・給与の3画面を、画面下部のナビゲーションで切り替えます。表示月は各画面で共通です。

初めて使う場合は「ログイン」と「カレンダーと日別一覧」から読み進めてください。給与の計算条件とメンバーの表示範囲は、各節で確認できます。起動方法は[起動・デプロイガイド](setup.md)を参照してください。

## ログイン

らくしふの従業員IDとパスワードを入力します。アプリは本人のスタッフID・所属店舗ID・所属業態IDを取得し、日本時間の当月シフトを読み込んでからログインを完了します。

アプリのログイン期限は1時間です。期限を過ぎた場合や、らくしふ側の認証が失効した場合は、ログインし直してください。ログイン試行は5分間に同一IPで30回、同一IPと従業員IDの組合せで5回までに制限しています。成功する試行も集計対象です。

画面上部の「ログアウト」で、アプリのセッションを削除します。公式らくしふの別のブラウザセッションをログアウトする操作は行いません。

## カレンダーと日別一覧

カレンダーには、自分が勤務する日の開始・終了時刻を表示します。自分が勤務しない日は、その日の出勤人数を表示します。見出しの矢印で前月・翌月へ移動できます。

スマートフォンなど画面幅が760px未満の場合は、大きな見出しカードを省きます。カレンダーの直上に、中央の表示年月、左右の前月・翌月ボタン、表示月の自分の勤務日数を表示します。勤務日数はカレンダーに自分のシフトが表示される日数です。PCでは従来の見出しカードを表示します。

日付を選ぶと、その日に自店舗で勤務するメンバーと勤務時刻、休憩時間を表示します。年齢とランクは、取得データにある場合に表示します。並び順は、自分、自分と勤務時間が重なる人、その他の人です。各グループ内では開始時刻で並べます。自分と退勤時刻が同じ人も識別できます。

勤務時間の重なりは、開始から終了までの区間で判定します。この判定では休憩を除かず、前日付と翌日付のシフトをまたいだ比較も行いません。例えば自分が10:00〜14:00、相手が14:00〜18:00の場合は、境界が接するだけなので重なりません。

カレンダーは既定で約121秒ごとに再取得します。検索・給与・開いている詳細画面には、この定期更新は適用されません。最新の情報を確認する場合は、対象画面を開き直すか、月を切り替えて再取得してください。サーバー側の月別キャッシュが有効な間は、直前に取得した内容を返します。

## メンバー検索と詳細

「検索」を開き、名前または従業員コードを入力します。前後の空白を除き、大文字・小文字を区別せずに部分一致で検索します。入力後250ミリ秒待って検索を開始し、最大100人を名前順に表示します。空欄の場合は、対象メンバーを最大100人表示します。

検索対象は、表示月のらくしふ応答に含まれる次の人です。

- 自店舗に所属するメンバー。
- 他店舗所属でも、その月に自店舗のシフトがあるメンバー。

本人は検索結果に含みません。シフト応答に含まれない人を、別の全社名簿から取得する機能はありません。

メンバーを選ぶと、本人の情報と、表示月の自店舗での勤務予定を確認できます。詳細画面の項目は、名前・従業員コード・誕生日・年齢です。合計勤務時間には、休憩を控除した値を表示します。他店舗での勤務予定は、この合計には含みません。

## 給与概算を確認する

「給与」を開き、時給と深夜割増率を入力します。深夜割増率の初期値は25%です。入力後250ミリ秒待って再計算し、シフト件数、予定時間、休憩、実働時間、深夜時間、月の給与概算を表示します。

時給が未入力の場合は、勤務時間を確認でき、給与欄には「時給を入力してください」と表示します。計算対象は、表示月に日付が属する本人の自店舗シフトです。月末の勤務が翌月にまたがる場合も、シフト開始日の月にまとめて計上します。

### 給与の計算方法

予定時間は開始から終了までの長さ、実働時間は予定時間から休憩を引いた長さです。深夜時間は22:00〜翌5:00のうち、休憩を除いた勤務時間です。

```text
実働時間（分） = 予定時間（分） − 休憩時間（分）
給与概算（円） = 時給 × 実働時間（分） / 60
              + 時給 × 深夜割増率（%） / 100 × 深夜時間（分） / 60
```

通常分と深夜割増分を月単位で合計し、最後に円単位で四捨五入します。計算にはPythonの`Decimal`を使い、シフトごと・日ごとの丸めは行いません。

例として、時給1,200円・深夜割増25%で21:00〜翌1:00に勤務し、21:15〜21:45と22:30〜23:00に休憩するシフトを考えます。時刻と金額は架空の条件です。

| 集計項目 | 時間 |
| --- | --- |
| 予定 | 240分 |
| 休憩 | 60分 |
| 実働 | 180分 |
| 深夜 | 150分 |

給与概算は`1,200 × 180 / 60 + 1,200 × 0.25 × 150 / 60 = 4,350円`となります。

複数の休憩はすべて控除します。重なった休憩はまとめて扱い、二重に控除しません。シフトの外にはみ出す休憩は、勤務区間と重なる部分だけを使います。

時刻は`24:00`・`25:00`のような翌日表記に対応しています。終了時刻が開始時刻より早い場合も、翌日に終了する勤務として扱います。

開始・終了のどちらかが欠けるシフトは給与計算から除外します。ただし、開始時刻があるシフトはシフト件数に含まれるため、件数と計算対象の件数が一致しない場合があります。

入力可能な範囲は時給0〜100,000円、深夜割増率0〜500%です。これはアプリの入力制約です。実際に適用する時給や割増率を自動でらくしふから取得する処理はありません。

### 給与概算に含まないもの

予定シフトを用いるため、遅刻・早退・欠勤・打刻実績などは反映しません。残業割増、休日割増、交通費、手当、税金、社会保険料も含みません。他店舗での勤務や、別の締め日による集計には対応していません。

表示額は、給与明細や実際の支給額と一致することを保証するものではありません。確認したい月の予定時間と、入力した条件による概算を読むための機能です。

### 入力した給与設定の保存

時給と深夜割増率は、同じブラウザの同じサイト内で、利用者IDごとに`localStorage`へ保存します。計算時にはアプリのサーバーへ送りますが、給与設定をサーバーに永続保存する処理はありません。

ログアウトしても保存値は消えません。別端末・別ブラウザ・別URLでは共有されず、ブラウザのサイトデータを削除すると失われます。保存機能を利用できないブラウザでも、入力した値で計算できます。

## 困ったとき

ログインや起動時の問題は[トラブル対応](setup.md#トラブル対応)を参照してください。解決しない不具合や機能要望はGitHub Issuesで受け付けます。公開の報告には実在する従業員情報や認証情報を含めず、架空の値に置き換えてください。

## 用語

| 用語 | 意味 |
| --- | --- |
| 予定時間 | シフトの開始から終了までの時間。休憩を含む |
| 実働時間 | 予定時間からシフトに記録された休憩を控除した時間。実績の打刻時間ではない |
| 深夜時間 | 22:00〜翌5:00と勤務区間が重なる時間から、休憩を控除した値 |
| 深夜割増率 | 深夜時間に、通常の時給へ加算する割合 |
| localStorage | ブラウザがサイトごとに保持する保存領域 |
